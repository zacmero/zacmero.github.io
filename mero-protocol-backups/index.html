Mero Protocol Backups

A private, owner-operated utility that stores encrypted Mero Protocol database backup artifacts in the owner's Google Drive.

Google Drive access

The utility requests the drive.file permission. It can access only files and folders created or explicitly opened through this application. It does not browse or read unrelated Drive content.

Operation

Backups are encrypted before upload. The utility is not offered to other users and does not sell, advertise with, or share Google user data.
