Privacy Policy

Application: Mero Protocol Backups
Effective date: September 4, 2026

Purpose

Mero Protocol Backups is a private, owner-operated utility. It uploads encrypted database backup artifacts to the owner's Google Drive for disaster recovery.

Google user data accessed

The application requests Google's drive.file scope. This permits access only to Drive files and folders created by, or explicitly opened with, this application. The utility does not request access to unrelated Drive files.

Use and storage

  • Database backup content is encrypted locally before upload.
  • Google authorization tokens are stored only on the controlled backup runner and are restricted from public access.
  • Google user data is used only to create, verify, retain, and remove the application's own backup artifacts.
  • Data is not sold, used for advertising, or shared with third parties.

Retention and deletion

Backup generations are retained according to the owner's recovery policy. The owner may delete artifacts in Drive, revoke access through the Google Account permissions page, or request deletion using the contact below.

Security

The utility uses encrypted backup artifacts, least-privilege OAuth access, restricted credential files, and verification of uploaded backup receipts. No security method can guarantee absolute protection.

Contact

Questions or deletion requests: z4cmero@gmail.com.
